# Unitcommit

Do the power numbers add up?

The cabinet factor is applied first. This check then compares the power used with the power asked. A mismatch is refused. A plan of on and off is not a dispatch by itself, and the width of that plan has to match the problem.

It takes the charger group from Loadclear and the factor from Cabinetfield, as plain values. Phasepin grades the clock after a pass. The plan is described in [docs/ISING-HAMILTONIAN.md](docs/ISING-HAMILTONIAN.md).

It does not call a quantum computer, and it does not sign the record.
